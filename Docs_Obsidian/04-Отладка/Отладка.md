# Отладка

#debug #breakpoints #devtools

## Два мира отладки

В Electron есть **два типа процессов**, и они отлаживаются по-разному:

| Процесс | Код | Где отлаживать | Аналог |
|---|---|---|---|
| **Main** (Node.js) | `src/main/` | Cursor/VS Code debugger | Xcode debugger / AS debugger |
| **Renderer** (Chromium) | `src/renderer/` | Chrome DevTools | Safari Web Inspector / Chrome DevTools |
| **YTM View** (Chromium) | `src/renderer/ytmview/` | Отдельные DevTools | WebView debugging |

## Отладка Main Process

### Запуск с дебаггером

1. Откройте панель **Run and Debug** (`Cmd+Shift+D`)
2. Выберите конфигурацию **"Electron Main"**
3. Нажмите **F5** (или зелёную кнопку Play)

> [!info] Конфигурация
> Файл `.vscode/launch.json` уже настроен:
> ```json
> {
>   "type": "node",
>   "request": "launch",
>   "name": "Electron Main",
>   "runtimeExecutable": "${workspaceFolder}/node_modules/@electron-forge/cli/script/vscode.sh",
>   "cwd": "${workspaceFolder}",
>   "console": "integratedTerminal"
> }
> ```

### Брейкпоинты в Main Process

Работают **точно как в Xcode / Android Studio**:

1. Откройте `src/main/index.ts`
2. Кликните слева от номера строки → появится 🔴 красная точка
3. Запустите через F5
4. Когда выполнение дойдёт до точки — приложение остановится

### Навигация при остановке

| Клавиша | Действие | Аналог в Xcode/AS |
|---|---|---|
| **F10** | Step Over (следующая строка) | Step Over |
| **F11** | Step Into (войти в функцию) | Step Into |
| **Shift+F11** | Step Out (выйти из функции) | Step Out |
| **F5** | Continue (продолжить) | Continue |
| **Shift+F5** | Stop (остановить) | Stop |

### Панели при отладке

| Панель | Назначение |
|---|---|
| **Variables** | Все переменные в текущем scope |
| **Watch** | Добавьте выражения для отслеживания (например `store.get("general")`) |
| **Call Stack** | Стек вызовов (идентично Xcode) |
| **Debug Console** | Выполнение выражений в контексте текущей остановки |

## Отладка Renderer Process (Chrome DevTools)

### Как открыть DevTools

**В dev-режиме (`yarn start`):**
- DevTools открываются **автоматически** для каждого окна (в отдельном окне)

**В production (для YTM View):**
1. Включите `developer.enableDevTools` в настройках приложения
2. Правый клик в области YouTube Music → "Open Developer Tools"

### Вкладки DevTools

| Вкладка | Назначение | Аналог |
|---|---|---|
| **Elements** | Инспекция DOM (HTML-дерево) | View Hierarchy (Xcode) / Layout Inspector (AS) |
| **Console** | Логи + выполнение JS | Logcat / Xcode Console |
| **Sources** | Исходники + брейкпоинты | Debugger |
| **Network** | Сетевые запросы | Charles Proxy / Network Inspector |
| **Application** | localStorage, cookies, session | SharedPreferences viewer |
| **Performance** | Профайлинг | Instruments / Android Profiler |

### Брейкпоинты в Renderer

1. В DevTools перейдите на вкладку **Sources**
2. Найдите файлы в дереве `src/renderer/`
3. Кликните по номеру строки → брейкпоинт
4. Работает как в основном дебаггере

## Полезные приёмы

### Быстрый лог без перезапуска (в DevTools Console)

```javascript
// Получить текущие настройки (в main DevTools невозможно, только через IPC)
// В YTM View Console:
window.__YTMD_HOOK__.ytmStore.getState()

// В Main Window Console:
window.ytmd.memoryStore.get("ytmViewLoading")
```

### Отладка IPC-сообщений

В DevTools Console renderer-процесса:

```javascript
// Перехват всех IPC-сообщений (добавьте в preload.ts для дебага):
const originalSend = ipcRenderer.send;
ipcRenderer.send = (...args) => {
  console.log('IPC SEND:', ...args);
  return originalSend.apply(ipcRenderer, args);
};
```

### Network tab для YouTube Music

Открыв DevTools для YTM View (через developer.enableDevTools), на вкладке Network видно:
- Запросы к YouTube Music API
- Загрузку обложек треков
- WebSocket-соединения

## Куда смотреть при проблемах

| Проблема | Где искать |
|---|---|
| Приложение не запускается | Терминал (main process логи) |
| Окно белое/пустое | DevTools > Console (renderer ошибки) |
| YouTube Music не загружается | DevTools YTM View > Console + Network |
| Интеграция не работает | Терминал + `src/main/integrations/` |
| IPC не доходит | Console обоих процессов + проверка `event.sender` |
| Стиль сломался | DevTools > Elements > Styles |
