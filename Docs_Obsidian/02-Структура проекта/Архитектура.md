# Архитектура проекта

#architecture #structure

## Что это за проект

**YouTube Music Desktop App** — десктопное приложение-обёртка вокруг YouTube Music. Загружает веб-версию YTM в встроенный браузер (BrowserView) и добавляет:
- Кастомный тайтлбар и системный трей
- Глобальные горячие клавиши
- Интеграции (Discord, Last.fm, HTTP API)
- Desktop-фичи (progress bar в таскбаре, уведомления)

## Процессная модель

```
┌──────────────────────────────────────────────────┐
│                  MAIN PROCESS                     │
│               (src/main/index.ts)                 │
│                                                   │
│  ┌─────────┐  ┌──────────┐  ┌─────────────────┐ │
│  │  Store   │  │ Memory   │  │ Player State    │ │
│  │  (Conf)  │  │ Store    │  │ Store           │ │
│  └─────────┘  └──────────┘  └─────────────────┘ │
│                                                   │
│  ┌─────────────────────────────────────────────┐ │
│  │            Integrations                      │ │
│  │  Companion │ Discord │ LastFM │ Notifications│ │
│  └─────────────────────────────────────────────┘ │
│                    ▲ IPC ▼                        │
├──────────────────────────────────────────────────┤
│              RENDERER PROCESSES                    │
│                                                   │
│  ┌──────────┐ ┌──────────┐ ┌──────────────────┐ │
│  │  Main    │ │ Settings │ │ Authorize        │ │
│  │  Window  │ │ Window   │ │ Companion Window │ │
│  │  (Vue)   │ │ (Vue)    │ │ (Vue)            │ │
│  └──────────┘ └──────────┘ └──────────────────┘ │
│                                                   │
│  ┌──────────────────────────────────────────────┐│
│  │        YTM BrowserView                        ││
│  │    (music.youtube.com + preload хуки)         ││
│  └──────────────────────────────────────────────┘│
└──────────────────────────────────────────────────┘
```

> [!important] Аналогия с мобильной разработкой
> - **Main Process** = AppDelegate/Application + ViewModel слой + Services
> - **Renderer Process** = UI Layer (Activity/Fragment/SwiftUI View)
> - **BrowserView** = WebView/WKWebView
> - **IPC** = Intent/BroadcastReceiver (Android) / NotificationCenter (iOS)
> - **Store (Conf)** = SharedPreferences / UserDefaults
> - **MemoryStore** = ViewModel state / @Published properties

## Каждое окно = отдельный процесс

Каждое окно приложения имеет:

| Файл | Назначение | Аналог |
|---|---|---|
| `index.html` | HTML-точка входа | `activity_main.xml` / Storyboard |
| `renderer.ts` | Инициализация Vue app | `onCreate()` / `viewDidLoad()` |
| `preload.ts` | Мост между Main и Renderer | Service binding / Protocol |
| `Index.vue` | Корневой компонент | Root Fragment / Root View |

---

## Стейт-менеджмент

| Стор | Персистентный | Где живёт | Аналог |
|---|---|---|---|
| **Conf (Store)** | Да (`config.json`) | Main process | SharedPreferences / UserDefaults |
| **MemoryStore** | Нет (RAM) | Main process | ViewModel state |
| **PlayerStateStore** | Нет (RAM) | Main process | Media session state |
