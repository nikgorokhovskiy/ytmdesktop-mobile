# Mobile — Сборка и запуск

#mobile #build #run #android #ios #gradle #tuist

## Команды

### Android (из `mobile/`)

| Команда | Назначение | Desktop-аналог |
|---|---|---|
| `./gradlew :androidApp:assembleDebug` | Debug APK (без подписи) | `yarn start` |
| `./gradlew :androidApp:assembleRelease` | Release APK (с ProGuard) | `yarn make` |
| `./gradlew :androidApp:installDebug` | Установить debug на устройство | — |
| `./gradlew :androidApp:bundleRelease` | AAB для Google Play | — |
| `./gradlew :shared:build` | Собрать shared-модуль | — |
| `./gradlew clean` | Очистить все артефакты | `rm -rf out/` |

### iOS (из `mobile/iosApp/`)

| Команда | Назначение | Desktop-аналог |
|---|---|---|
| `mise exec -- tuist generate` | Сгенерировать `.xcodeproj` | — |
| `mise exec -- tuist generate --open` | Сгенерировать и открыть Xcode | — |
| `mise exec -- tuist clean` | Очистить Tuist-кеш | — |

> [!important] Все Gradle-команды выполняются из `mobile/`, все Tuist-команды — из `mobile/iosApp/`

## Android — сборка и запуск

### Debug-сборка

```bash
cd mobile

# Собрать APK
./gradlew :androidApp:assembleDebug

# APK появится здесь:
# androidApp/build/outputs/apk/debug/androidApp-debug.apk
```

### Установка на устройство/эмулятор

```bash
# Собрать и установить одной командой
./gradlew :androidApp:installDebug

# Или вручную через adb
adb install androidApp/build/outputs/apk/debug/androidApp-debug.apk
```

> [!tip] Запуск из Android Studio
> 1. Открыть `mobile/` как проект в Android Studio
> 2. В верхней панели (toolbar) — выпадающий список слева от кнопки Run
> 3. Выбрать модуль **androidApp**
> 4. Справа выбрать устройство/эмулятор
> 5. Нажать **Run** (Ctrl+R на Mac)
>
> Если модуля нет в списке:
> Edit Configurations → **+** → Android App → Module: `ytmd-mobile.androidApp.main` → OK

### Создание эмулятора

```bash
# Скачать образ
sdkmanager "system-images;android-35;google_apis;arm64-v8a"

# Создать эмулятор
avdmanager create avd -n Pixel_8 -k "system-images;android-35;google_apis;arm64-v8a" -d pixel_8

# Запустить
emulator -avd Pixel_8
```

> [!note] Рекомендуемый эмулятор
> **Pixel 8**, API 35 (Android 15), Google APIs, arm64 (для Apple Silicon Mac).

## Android — Release-сборка

### Подпись (signing)

Для релизной сборки нужен keystore:

```bash
# Создать keystore (одноразово)
keytool -genkey -v \
  -keystore ytmd-release.jks \
  -keyalg RSA -keysize 2048 \
  -validity 10000 \
  -alias ytmd
```

Добавить в `mobile/local.properties` (файл в `.gitignore`):

```properties
signing.keystore.path=../ytmd-release.jks
signing.keystore.password=your_password
signing.key.alias=ytmd
signing.key.password=your_password
```

> [!warning] Безопасность
> **Никогда** не коммитьте `local.properties` и `.jks` файлы в Git.
> `local.properties` уже добавлен в `.gitignore`.

### Сборка Release APK

```bash
./gradlew :androidApp:assembleRelease

# Результат:
# androidApp/build/outputs/apk/release/androidApp-release.apk
```

### Сборка AAB (для Google Play)

```bash
./gradlew :androidApp:bundleRelease

# Результат:
# androidApp/build/outputs/bundle/release/androidApp-release.aab
```

## iOS — генерация проекта (Tuist)

iOS-проект **не хранится в Git** — он генерируется из Swift-манифестов через Tuist.

### Файлы проекта

| Файл | Назначение | В Git? |
|---|---|---|
| `Project.swift` | Описание таргетов, настроек, скриптов | ✅ Да |
| `Tuist.swift` | Глобальная конфигурация Tuist | ✅ Да |
| `.mise.toml` | Версия Tuist (4.146.0) | ✅ Да |
| `iosApp.xcodeproj` | Сгенерированный Xcode-проект | ❌ В `.gitignore` |
| `iosApp.xcworkspace` | Сгенерированный workspace | ❌ В `.gitignore` |

### Генерация

```bash
cd mobile/iosApp

# Установить Tuist (первый раз)
mise install

# Сгенерировать и открыть в Xcode
mise exec -- tuist generate --open

# Или без открытия
mise exec -- tuist generate --no-open
```

> [!info] Когда перегенерировать?
> - После изменения `Project.swift`
> - После добавления/удаления Swift-файлов
> - После pull из Git (другие разработчики могли изменить `Project.swift`)

### Что делает `Project.swift`

```swift
// Определяет:
// 1. iOS target (bundleId, deployment target, sources)
// 2. Pre-build script — вызывает Gradle для сборки shared framework
// 3. Framework search paths — где искать shared.framework
// 4. Linker flags — линковка libsqlite3 и shared framework
```

## iOS — сборка и запуск

### Из Xcode (рекомендуемый способ)

```bash
cd mobile/iosApp
mise exec -- tuist generate --open
```

В Xcode:
1. Выбрать scheme **iosApp**
2. Выбрать Simulator (например iPhone 16)
3. Нажать **Run** (Cmd+R)

> [!info] Как это работает
> При Build в Xcode срабатывает **pre-build script**, который:
> 1. Вызывает `./gradlew :shared:embedAndSignAppleFrameworkForXcode`
> 2. Kotlin/Native компилирует shared-модуль в `.framework` под нужную архитектуру
> 3. Framework копируется в derived data
> 4. Xcode линкует его и компилирует Swift-файлы
>
> Первая сборка занимает **3-5 минут** (компиляция Kotlin/Native). Последующие — быстрее (кеширование).

### Из командной строки

```bash
# Сгенерировать проект
cd mobile/iosApp
mise exec -- tuist generate --no-open

# Собрать через xcodebuild
xcodebuild -workspace iosApp.xcworkspace \
  -scheme iosApp \
  -sdk iphonesimulator \
  -destination "platform=iOS Simulator,name=iPhone 16" \
  build
```

### Сборка для физического устройства

```bash
xcodebuild -workspace iosApp.xcworkspace \
  -scheme iosApp \
  -sdk iphoneos \
  -configuration Release \
  -archivePath build/iosApp.xcarchive \
  archive
```

> [!warning] Code Signing
> Для установки на физическое устройство нужен Apple Developer аккаунт и provisioning profile. Для Simulator подпись не нужна.

## Shared-модуль — сборка отдельно

```bash
cd mobile

# Собрать все таргеты
./gradlew :shared:build

# Только Android
./gradlew :shared:compileKotlinAndroid

# Только iOS (для конкретной архитектуры)
./gradlew :shared:compileKotlinIosArm64          # устройство
./gradlew :shared:compileKotlinIosSimulatorArm64  # симулятор (Apple Silicon)
./gradlew :shared:compileKotlinIosX64             # симулятор (Intel)

# Собрать iOS framework
./gradlew :shared:linkDebugFrameworkIosArm64
./gradlew :shared:linkDebugFrameworkIosSimulatorArm64
```

## Проблемы и решения

### Gradle: `Could not find or load main class org.gradle.wrapper.GradleWrapperMain`

Нет `gradle-wrapper.jar`. Скачать:

```bash
cd mobile
curl -L "https://raw.githubusercontent.com/gradle/gradle/v8.11.1/gradle/wrapper/gradle-wrapper.jar" \
  -o gradle/wrapper/gradle-wrapper.jar
```

### Gradle: `Unable to locate a Java Runtime`

Нет JDK или не указан `JAVA_HOME`. Создать/обновить `mobile/local.properties`:

```properties
org.gradle.java.home=/path/to/Android Studio.app/Contents/jbr/Contents/Home
```

### Gradle: `SDK location not found`

Добавить в `mobile/local.properties`:

```properties
sdk.dir=/Users/YOUR_USER/Library/Android/sdk
```

### Gradle daemon не запускается

```bash
./gradlew --stop
./gradlew :androidApp:assembleDebug --info
```

### iOS: `No such module 'shared'`

Shared framework не собран. Пересобрать:

```bash
cd mobile
./gradlew :shared:linkDebugFrameworkIosSimulatorArm64
```

Затем в Xcode: Cmd+Shift+K (Clean) → Cmd+B (Build).

### iOS: `Undefined symbol: _sqlite3_*`

`libsqlite3` не линкуется. Проверить `Project.swift`:

```swift
"OTHER_LDFLAGS": "$(inherited) -lsqlite3 -framework shared",
```

Перегенерировать: `mise exec -- tuist generate`

### iOS: нет `.xcodeproj`

Проект генерируется через Tuist:

```bash
cd mobile/iosApp
mise install              # установить Tuist (первый раз)
mise exec -- tuist generate
```

### Tuist: `command not found`

```bash
# Установить mise
curl https://mise.run | sh
eval "$(~/.local/bin/mise activate zsh)"

# Установить Tuist
cd mobile/iosApp
mise install
```
