## Библиотека: electron-log

Проект использует `electron-log` (v5.4) — это обёртка над `console.log` с записью в файл.

> [!info] Аналогия
> `electron-log` = `Timber` (Android) / `os_log` + `OSLog` (iOS)

---

## Использование в коде

### Main Process

```typescript
import log from "electron-log";

log.info("Application launched");        // [main][info]
log.warn("Something suspicious");        // [main][warn]
log.error("Something broke", error);     // [main][error]
log.debug("Debug info");                 // [main][debug]
log.verbose("Very detailed");            // [main][verbose]
```

### Renderer Process

```typescript
// Обычный console — перехватывается electron-log
console.log("From renderer");
console.error("Renderer error");
console.warn("Renderer warning");
```

> [!note] Как это работает
> `electron-log` инициализируется с `spyRendererConsole: true` — все `console.*` вызовы из renderer-процессов автоматически попадают в файловые логи main process.

## Формат логов

### Консоль (терминал)

```
[main][info] Application launched
[main][info] Created memory store
[main][info] Application ready
[main][error] Something went wrong
```

Формат: `[processType][level]{text}`

### Файл

```
[2026-02-11 14:30:45.123][main][info] Application launched
[2026-02-11 14:30:45.456][main][info] Created memory store
```

Формат: `[y-m-d h:i:s.ms][processType][level]{text}`

## Расположение файлов логов

| Платформа | Путь |
|---|---|
| **macOS** | `~/Library/Logs/YouTube Music Desktop App/main.log` |
| **Windows** | `%USERPROFILE%\AppData\Roaming\YouTube Music Desktop App\logs\main.log` |
| **Linux** | `~/.config/YouTube Music Desktop App/logs/main.log` |

### Быстрый просмотр на macOS

```bash
# Последние 50 строк
tail -50 ~/Library/Logs/YouTube\ Music\ Desktop\ App/main.log

# Следить в реальном времени
tail -f ~/Library/Logs/YouTube\ Music\ Desktop\ App/main.log

# Поиск ошибок
grep "\[error\]" ~/Library/Logs/YouTube\ Music\ Desktop\ App/main.log
```

## Где смотреть логи при разработке

| Источник логов | Где смотреть | Что видно |
|---|---|---|
| **Main process** | Терминал Cursor (где `yarn start`) | `log.info()`, `log.error()`, etc. |
| **Main window renderer** | Chrome DevTools → Console | `console.log()` из Vue-компонентов |
| **Settings window renderer** | Chrome DevTools → Console (settings) | Логи настроек |
| **YTM View** | Chrome DevTools → Console (ytmView) | Логи YouTube Music + инжектированных скриптов |

## Фильтрация логов в коде

Проект фильтрует логи:

### Спам-фильтр
```typescript
// Сообщения о third-party cookies от YTM не пишутся в файл
const isSpamLogMessage = (data: unknown): boolean =>
  typeof data === "string" && /third-party cookie will be blocked\./i.test(data);
```

### Редакция URL
```typescript
// URL-пути скрываются для безопасности
// https://music.youtube.com/watch?v=ABC123 → https://music.youtube.com/[REDACTED]
data.replaceAll(/(?<=((https|http):\/\/)?.{1,64}(\..{1,64})?\..{1,64}\/)([\S]+)/gm, "[REDACTED]");
```

## Обработка ошибок

При необработанной ошибке в main process:

1. `electron-log` перехватывает ошибку (`log.errorHandler.startCatching`)
2. Показывает диалог пользователю с деталями
3. Предлагает: "Copy to Clipboard and Exit" / "Exit" / "Continue" (dev only)

```
YouTube Music Desktop App Crashed

Environment Details:
    2.0.10
    Electron 38.0.0
    macOS 15.2.0

Name: TypeError
Message: Cannot read property 'x' of undefined
```
