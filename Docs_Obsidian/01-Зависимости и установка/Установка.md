## Установка Node.js

```bash
# Вариант 1: Homebrew
brew install node@20

# Вариант 2: nvm (рекомендуется — позволяет переключать версии)
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.7/install.sh | bash
nvm install 20
nvm use 20

# Проверка
node -v   # v20.x.x
npm -v    # 10.x.x
```

## Установка Yarn 4.5.1

Проект использует **Yarn 4** (Modern/Berry), не классический Yarn 1. Установка через **Corepack** — встроенный менеджер в Node.js:

```bash
# Включаем Corepack
corepack enable

# Или через sudo если ошибка прав
sudo corepack enable

# Или если Node.js из Homebrew
brew install corepack
```

> [!info] Как это работает
> `package.json` содержит поле `"packageManager": "yarn@4.5.1"`.
> После `corepack enable` при вызове `yarn` Corepack автоматически скачает и использует нужную версию.
> Бинарник Yarn лежит в `.yarn/releases/yarn-4.5.1.cjs`.

```bash
# Проверка (в директории проекта)
cd /path/to/ytmdesktop-mobile
yarn -v   # 4.5.1
```

## Установка зависимостей проекта

```bash
yarn install
```

> [!note] Аналогия
> `yarn install` = `pod install` (CocoaPods) = `./gradlew dependencies` (Gradle)

Зависимости ставятся в `node_modules/` (аналог `.build/` в SPM или `Pods/` в CocoaPods).

## Расширения IDE (Cursor / VS Code)

Проект рекомендует расширения в `.vscode/extensions.json`:

| Расширение | ID | Назначение |
|---|---|---|
| **Vue - Official (Volar)** | `vue.volar` | IntelliSense для `.vue` файлов |
| **ESLint** | `dbaeumer.vscode-eslint` | Линтер (аналог ktlint / SwiftLint) |
| **Prettier** | `esbenp.prettier-vscode` | Автоформатирование |
| **EditorConfig** | `editorconfig.editorconfig` | Единые настройки редактора |

> [!tip] Установка
> Cursor/VS Code покажет уведомление «Install recommended extensions» при открытии проекта. Нажмите Install All.

## Основные зависимости

### Production
- **electron** — фреймворк десктопного приложения
- **vue** (3.5) — UI фреймворк
- **fastify** (5.3) — HTTP-сервер (Companion API)
- **socket.io** (4.8) — WebSocket (realtime updates)
- **conf** (10.2) — хранилище конфигурации (файл JSON)
- **electron-log** (5.4) — логирование

### Dev
- **@electron-forge/cli** — CLI для сборки/упаковки
- **@electron-forge/plugin-vite** — интеграция Vite
- **vite** (5.4) — бандлер (аналог webpack, но быстрее)
- **typescript** (5.8) — компилятор TypeScript
- **eslint** + **prettier** — линтинг и форматирование
