# Mobile — Архитектура проекта

#mobile #architecture #kmp #cleanarchitecture

## Что это за проект

**YTMD Mobile** — нативные мобильные клиенты YouTube Music для Android и iOS на базе **Kotlin Multiplatform** (KMP). Общая бизнес-логика — в Kotlin, нативные UI — в Jetpack Compose (Android) и SwiftUI (iOS).

> [!info] Связь с Desktop
> Desktop-приложение оборачивает веб-версию YouTube Music в Electron (BrowserView).
> Mobile-приложение использует **Innertube API** напрямую — тот же JSON API, что использует само приложение YouTube Music.

## Аналогия с Desktop

| Концепция | Desktop (Electron) | Mobile (KMP) |
|---|---|---|
| **Точка входа** | `src/main/index.ts` | `YtmdApp.kt` / `iOSApp.swift` |
| **UI слой** | Vue 3 components | Compose / SwiftUI |
| **Навигация** | BrowserWindow | Navigation Compose / NavigationStack |

| **Хранилище** | Conf (JSON файл) | SQLDelight (SQLite) |

| **Аутентификация** | BrowserView + cookies | WebView + CookieStore |

| **IPC** | Electron IPC | expect/actual + Koin |

## Модули Gradle

| Модуль | Тип | Плагины | Описание |
|---|---|---|---|
| `:shared` | KMP Library | `kotlin.multiplatform`, `android.library`, `sqldelight` | Общая логика |
| `:androidApp` | Android App | `android.application`, `kotlin.compose` | Android UI |

> [!note] iOS модуль
> iOS-приложение не является Gradle-модулем. Xcode-проект генерируется через **Tuist** из `Project.swift` (не хранится в Git).
> При сборке в Xcode pre-build script вызывает Gradle, который компилирует `shared` в `.framework` через Kotlin/Native.
> iOS-код импортирует его как `import shared`.
>
> ```bash
> cd mobile/iosApp
> mise exec -- tuist generate --open   # сгенерировать и открыть
> ```

## Kotlin Multiplatform — expect/actual

Механизм `expect`/`actual` — способ написать один интерфейс, а реализации сделать платформенными:

```kotlin
// commonMain — объявление (expect)
expect class PlayerController {
    val state: StateFlow<PlayerState>
    fun play(streamUrl: String, track: Track)
    fun pause()
    fun release()
}

// androidMain — реализация через ExoPlayer
actual class PlayerController(context: Context) {
    private val exoPlayer = ExoPlayer.Builder(context).build()
    actual val state = MutableStateFlow(PlayerState())
    actual fun play(streamUrl: String, track: Track) {
        exoPlayer.setMediaItem(MediaItem.fromUri(streamUrl))
        exoPlayer.prepare()
        exoPlayer.play()
    }
    // ...
}

// iosMain — реализация (state bridge для AVPlayer из Swift)
actual class PlayerController {
    actual val state = MutableStateFlow(PlayerState())
    actual fun play(streamUrl: String, track: Track) {
        // Обновляет state; реальный AVPlayer управляется из Swift
    }
    // ...
}
```

> [!info] Аналогия
> `expect/actual` ≈ `interface` + `implements` в Java, но на уровне **компилятора и source sets**.
> Desktop аналог — нет прямого аналога, т.к. Electron работает на одной платформе (Chromium).

## Dependency Injection (Koin)

Koin — multiplatform DI фреймворк. Конфигурация:

```kotlin
// sharedModule — общие зависимости
val sharedModule = module {
    single { InnertubeApi(httpClient = get(), authRepository = get()) }
    single<MusicRepository> { MusicRepositoryImpl(innertubeApi = get()) }
    factory { SearchUseCase(musicRepository = get()) }
}

// platformModule — платформенные (в androidMain / iosMain)
val platformModule = module {
    single { PlayerController(get<Context>()) }    // Android
    // или
    single { PlayerController() }                  // iOS
}
```

Инициализация:

```kotlin
// Android — в YtmdApp.kt (Application class)
startKoin {
    androidContext(this@YtmdApp)
    modules(sharedModule, platformModule)
}

// iOS — из iOSApp.swift → вызов Kotlin-функции
KoinInitializerKt.doInitKoin()
```

## Ключевые модели данных

| Модель | Поля | Описание |
|---|---|---|
| `Track` | id, title, artist, album, duration, thumbnailUrl, streamUrl | Трек |
| `Album` | id, title, artist, thumbnailUrl, tracks | Альбом |
| `Playlist` | id, title, thumbnailUrl, trackCount | Плейлист |
| `SearchResult` | sealed: TrackResult, AlbumResult, ArtistResult, PlaylistResult | Результат поиска |
| `PlayerState` | currentTrack, isPlaying, progressMs, durationMs, repeatMode, shuffleEnabled, queue | Состояние плеера |
| `AuthState` | sealed: Authenticated(cookies), Unauthenticated | Состояние авторизации |
| `StreamInfo` | url, mimeType, bitrate, codec, contentLength | Данные аудиопотока |
| `DownloadState` | sealed: NotDownloaded, Downloading, Downloaded, Failed | Статус загрузки |
