> [!info] Сравнение с Desktop
> Desktop использует **веб-плеер YouTube Music** внутри BrowserView — воспроизведение полностью управляется веб-страницей.
> Mobile использует **нативные плееры** (ExoPlayer/AVPlayer) — полный контроль над воспроизведением, буферизацией, очередью.


Состояние плеера:

```kotlin
data class PlayerState(
    val currentTrack: Track? = null,
    val isPlaying: Boolean = false,
    val progressMs: Long = 0L,
    val durationMs: Long = 0L,
    val repeatMode: RepeatMode = RepeatMode.OFF,  // OFF, ONE, ALL
    val shuffleEnabled: Boolean = false,
    val queue: List<Track> = emptyList(),
)
```

`PlayerState` — immutable data class, обновляется через `StateFlow`. UI подписывается на `state` и перерисовывается автоматически.

## Android — ExoPlayer / Media3

### Компоненты

| Класс | Назначение | Файл |
|---|---|---|
| `AndroidPlayerController` | actual-реализация PlayerController | `androidMain/.../player/` |
| `MusicService` | Foreground service для фонового воспроизведения | `androidApp/.../service/` |
| `ExoPlayer` | Media3 плеер | Из библиотеки `media3-exoplayer` |
| `MediaSession` | Системная медиа-сессия | Из библиотеки `media3-session` |

### AndroidPlayerController

```kotlin
actual class PlayerController(context: Context) {
    private val exoPlayer = ExoPlayer.Builder(context).build()
    private val _state = MutableStateFlow(PlayerState())
    actual val state = _state.asStateFlow()

    actual fun play(streamUrl: String, track: Track) {
        val mediaItem = MediaItem.fromUri(streamUrl)
        exoPlayer.setMediaItem(mediaItem)
        exoPlayer.prepare()
        exoPlayer.play()
        updateState { copy(currentTrack = track, isPlaying = true) }
    }

    // ExoPlayer Listener обновляет state автоматически
    init {
        exoPlayer.addListener(object : Player.Listener {
            override fun onIsPlayingChanged(isPlaying: Boolean) {
                updateState { copy(isPlaying = isPlaying) }
            }
            override fun onPlaybackStateChanged(state: Int) {
                if (state == Player.STATE_ENDED) next()
            }
        })
        // + coroutine для обновления progressMs каждые 500ms
    }
}
```

### MusicService (Foreground Service)

```kotlin
class MusicService : MediaSessionService() {
    private var mediaSession: MediaSession? = null

    override fun onCreate() {
        super.onCreate()
        val player = ExoPlayer.Builder(this).build()
        mediaSession = MediaSession.Builder(this, player).build()
    }

    override fun onGetSession(controllerInfo: MediaSession.ControllerInfo) = mediaSession
}
```

## iOS — AVPlayer

### Компоненты

| Класс | Назначение | Файл |
|---|---|---|
| `IosPlayerController` | actual-реализация (state management) | `iosMain/.../player/` |
| `PlayerBridge` | Swift: управление AVPlayer | `iosApp/.../Services/` |
| `AudioSessionManager` | AVAudioSession + MPRemoteCommandCenter | `iosApp/.../Audio/` |

### IosPlayerController (Kotlin)

```kotlin
actual class PlayerController {
    private val _state = MutableStateFlow(PlayerState())
    actual val state = _state.asStateFlow()

    // Вызывается из Swift через PlayerBridge
    fun updateProgress(positionMs: Long, durationMs: Long) {
        _state.value = _state.value.copy(
            progressMs = positionMs,
            durationMs = durationMs
        )
    }

    fun updatePlaybackState(isPlaying: Boolean) {
        _state.value = _state.value.copy(isPlaying = isPlaying)
    }
}
```

> [!note] Swift ↔ Kotlin bridge
> `IosPlayerController` экспортируется как часть shared framework. Swift-код (`PlayerBridge`) вызывает методы `updateProgress()` и `updatePlaybackState()`, а Kotlin обновляет `StateFlow`. SwiftUI подписывается на state через `Combine`-обёртку.

### PlayerBridge (Swift)

```swift
final class PlayerBridge: ObservableObject {
    private var player: AVPlayer?
    private var playerController: PlayerController?

    func play(url: URL, trackId: String) {
        let item = AVPlayerItem(url: url)
        player = AVPlayer(playerItem: item)
        player?.play()
        setupTimeObserver()
    }

    private func setupTimeObserver() {
        let interval = CMTime(seconds: 0.5, preferredTimescale: 600)
        player?.addPeriodicTimeObserver(forInterval: interval, queue: .main) {
            [weak self] time in
            let positionMs = Int64(time.seconds * 1000)
            let durationMs = Int64(self?.player?.currentItem?.duration.seconds ?? 0 * 1000)
            self?.playerController?.updateProgress(
                positionMs: positionMs,
                durationMs: durationMs
            )
        }
    }
}
```

## Сравнение платформ

| Аспект | Android | iOS |
|---|---|---|
| **Плеер** | ExoPlayer (Media3) | AVPlayer |
| **Background** | Foreground Service + MediaSession | AVAudioSession (.playback) + UIBackgroundModes |
| **Notification** | MediaSession → автоматическая | MPNowPlayingInfoCenter + MPRemoteCommandCenter |
| **Lock screen** | MediaSession (автоматически) | MPNowPlayingInfoCenter |
| **Кнопки наушников** | MediaSession (автоматически) | MPRemoteCommandCenter |
| **Кодеки** | MP4/AAC, WebM/Opus, MP3 | MP4/AAC (Opus через WebM — ограничено) |
| **Буферизация** | ExoPlayer автоматически | AVPlayer автоматически |

> [!warning] Кодек Opus на iOS
> AVPlayer **не поддерживает** Opus в контейнере WebM нативно. Необходимо либо:
> 1. Предпочитать AAC (itag 140/141) потоки для iOS
> 2. Либо использовать стороннюю библиотеку (FFmpeg/VLCKit)
>
> В текущей реализации `getStreamInfo()` выбирает поток с максимальным битрейтом — для iOS потребуется фильтрация по кодеку.

## Поток воспроизведения (end-to-end)

```
1. UI: Пользователь нажимает Play на треке
         │
2. UseCase: GetStreamUseCase(videoId)
         │
3. Repository: MusicRepositoryImpl.getStreamInfo(videoId)
         │
4. API: InnertubeApi.player(videoId)  →  YouTube Music сервер
         │                                      │
         │ ← PlayerResponse (streamingData.adaptiveFormats)
         │
5. Выбор лучшего аудиопотока (max bitrate, audio/*)
         │
6. PlayerStateManager.play(track)
         │
7. PlayerController.play(streamUrl, track)
         │
    ┌────┴────┐
    ▼         ▼
 Android:  iOS:
 ExoPlayer  AVPlayer
 .fromUri() .init(url:)
 .prepare() .play()
 .play()
         │
8. State обновляется через StateFlow
         │
9. UI перерисовывается (Compose recomposition / SwiftUI body)
```
