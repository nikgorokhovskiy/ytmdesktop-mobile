| Команда | Назначение | Аналог |
|---|---|---|
| `yarn start` | Dev-режим с hot reload | `./gradlew run` / Cmd+R в Xcode |

| `yarn make` | Сборка с инсталлером | `./gradlew bundle` / Archive в Xcode |
| `yarn make --arch x64` | Сборка для Intel Mac | — |
| `yarn make --arch arm64` | Сборка для Apple Silicon | — |
| `yarn lint` | Проверка линтером | `./gradlew lint` / `swiftlint` |
| `yarn lint:fix` | Автоисправление линтера | `swiftlint --fix` |
| `yarn prettier:fix` | Автоформатирование | `ktfmt` / `swift-format` |

## Dev-режим (разработка)

```bash
yarn start
```

Что происходит:
1. **Vite** компилирует TypeScript и собирает бандлы
2. Запускается **Electron** с dev-сервером
3. **Hot Reload** — изменения в `src/renderer/` применяются мгновенно (как Hot Reload в Flutter/Compose)
4. Изменения в `src/main/` перезапускают main process

> [!tip] DevTools
> В dev-режиме Chrome DevTools открывается автоматически для каждого окна (detached).

## Production-сборка

### Для текущей платформы

```bash
yarn make
```

### Для macOS конкретно

```bash
# Intel Mac
yarn make --arch x64

# Apple Silicon
yarn make --arch arm64
```

### Результат сборки

```
out/make/zip/darwin/arm64/
  └── YouTube Music Desktop App-2.0.10-arm64.zip
```

> [!warning] Текущий формат — ZIP
> macOS сборка создаёт только ZIP-архив (через `MakerZIP`).
> DMG и PKG **не настроены**. Для их добавления нужны пакеты:
> - `@electron-forge/maker-dmg`
> - `@electron-forge/maker-pkg`

## Система сборки

```
forge.config.ts          # Конфигурация Electron Forge
    │
    ├── Packager          # Упаковка приложения
    │   ├── executableName: youtube-music-desktop-app
    │   ├── icon: ./src/assets/icons/ytmd
    │   ├── protocols: ytmd://
    │   └── appCategory: public.app-category.music
    │
    ├── Makers            # Создание инсталлеров
    │   ├── MakerSquirrel   → Windows (.exe)
    │   ├── MakerZIP        → macOS (.zip)
    │   ├── MakerDeb        → Linux (.deb)
    │   └── MakerRpm        → Linux (.rpm)
    │
    ├── Plugins
    │   ├── Vite Plugin     # Сборка TS → JS через Vite
    │   │   ├── main build        → src/main/index.ts
    │   │   ├── preload builds    → 4 preload-скрипта
    │   │   └── renderer build    → Vue приложение
    │   ├── Auto Unpack Natives
    │   └── Fuses Plugin    # Безопасность Electron
    │
    └── Publishers
        └── GitHub          # Публикация релизов
```

## Vite-конфиги

| Файл | Собирает | Результат |
|---|---|---|
| `viteconfig/main.ts` | `src/main/index.ts` | `.vite/main/index.js` |
| `viteconfig/renderer.ts` | `src/renderer/windows/*/` | HTML + JS бандлы |
| `viteconfig/preload/main_window.ts` | Main window preload | preload.js |
| `viteconfig/preload/settings_window.ts` | Settings preload | preload.js |
| `viteconfig/preload/authorize_companion_window.ts` | Auth preload | preload.js |
| `viteconfig/preload/ytmview.ts` | YTM View preload | preload.js |

## Electron Fuses (безопасность при сборке)

| Fuse | Значение | Назначение |
|---|---|---|
| RunAsNode | **Disabled** | Нельзя запускать как Node.js |
| EnableCookieEncryption | **Enabled** | Шифрование cookies |
| EnableNodeOptionsEnvironmentVariable | **Disabled** | Нельзя передать NODE_OPTIONS |
| EnableNodeCliInspectArguments | **Disabled** | Нельзя подключить дебаггер извне |
| EnableEmbeddedAsarIntegrityValidation | **Enabled** | Проверка целостности ASAR |
| OnlyLoadAppFromAsar | **Enabled** | Загрузка только из ASAR |

## macOS-специфика при сборке

- **Auto-updates отключены** — требуется code signing (пока не настроено)
- **Ad-hoc подпись** для arm64 сбрасывается через Fuses
- **App Category:** `public.app-category.music`
- **Icon:** `src/assets/icons/ytmd.icns`
