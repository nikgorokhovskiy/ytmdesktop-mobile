## Установка JDK — используем встроенный из Android Studio

Android Studio поставляется с **JetBrains Runtime (JDK 21)** — его достаточно для сборки всего проекта. Отдельная установка JDK **не нужна**.

JDK из Android Studio находится по пути:

```
/Users/<USER>/Applications/Android Studio.app/Contents/jbr/Contents/Home
```

> [!info] Как это настроено
> Файл `mobile/local.properties` (не в Git) содержит:
> ```properties
> org.gradle.java.home=/Users/<USER>/Applications/Android Studio.app/Contents/jbr/Contents/Home
> ```
> Gradle автоматически использует этот JDK. Создай `local.properties` после клонирования проекта (см. раздел "Первый запуск" ниже).

Если Android Studio установлен через **JetBrains Toolbox**, путь будет:

```
/Users/<USER>/Applications/Android Studio.app/Contents/jbr/Contents/Home
```

Если установлен стандартно через DMG:

```
/Applications/Android Studio.app/Contents/jbr/Contents/Home
```

> [!tip] Альтернатива: отдельный JDK
> Если нужен JDK без Android Studio:
> ```bash
> brew install openjdk@17
> export JAVA_HOME=$(/usr/libexec/java_home -v 17)
> ```

## Установка Android Studio и SDK

```bash
# Через JetBrains Toolbox (рекомендуется)
# Или через Homebrew:
brew install --cask android-studio
```

После установки:

1. Открыть Android Studio → **SDK Manager** (Settings → Languages & Frameworks → Android SDK)
2. Установить:

| Компонент | Вкладка | Обязателен |
|---|---|---|
| **Android 15 (API 35)** | SDK Platforms | Да |
| **Android SDK Build-Tools 35** | SDK Tools | Да |
| **Android SDK Command-line Tools** | SDK Tools | Да |
| **Android SDK Platform-Tools** | SDK Tools | Да |
| **Android Emulator** | SDK Tools | Рекомендуется |

3. Настроить `ANDROID_HOME` (добавить в `~/.zshrc`):

```bash
export ANDROID_HOME=$HOME/Library/Android/sdk
export PATH=$PATH:$ANDROID_HOME/platform-tools
```

## Установка Xcode (для iOS)

```bash
# Из Mac App Store или:
xcode-select --install

# Проверка
xcodebuild -version   # Xcode 15.x+
```

> [!warning] Только macOS
> Сборка iOS-приложения возможна **только на macOS** с установленным Xcode.

После установки:
1. Открыть Xcode → Settings → Platforms → скачать **iOS 17+** Simulator
2. Принять лицензии: `sudo xcodebuild -license accept`

## Установка mise и Tuist

**mise** — менеджер версий инструментов (аналог `nvm`/`asdf`). Используется для закрепления версии Tuist.

```bash
# Установка mise (если ещё не установлен)
curl https://mise.run | sh

# Добавить в ~/.zshrc
eval "$(~/.local/bin/mise activate zsh)"
```

**Tuist** устанавливается автоматически через mise при первом запуске. Версия закреплена в `mobile/iosApp/.mise.toml`:

```toml
[tools]
tuist = "4.146.0"
```

```bash
# Установить Tuist (из директории iosApp)
cd mobile/iosApp
mise install

# Проверка
mise exec -- tuist version   # 4.146.0
```

> [!note] Зачем mise + Tuist?
> **Tuist** генерирует `.xcodeproj` из Swift-манифестов (`Project.swift`). Сгенерированный проект не хранится в Git — только декларативное описание.
> **mise** гарантирует одинаковую версию Tuist у всех разработчиков.
>
> Desktop-аналогия: `mise` ≈ `Corepack`, `Tuist` ≈ `Electron Forge` (система, которая генерирует конфигурацию сборки).

## Gradle Wrapper — не нужно устанавливать Gradle вручную

Проект использует **Gradle Wrapper** (`gradlew`). При первом запуске wrapper автоматически скачает Gradle 8.11.1.

```bash
cd mobile
./gradlew --version   # Скачает Gradle и покажет версию
```

> [!note] Аналогия с Desktop
> `./gradlew` = `yarn` — обёртка, которая гарантирует нужную версию менеджера сборки.
> `gradle-wrapper.properties` = `.yarnrc.yml` — фиксирует версию.

Если `gradle-wrapper.jar` отсутствует (он в `.gitignore`), скачать:

```bash
cd mobile
curl -L "https://raw.githubusercontent.com/gradle/gradle/v8.11.1/gradle/wrapper/gradle-wrapper.jar" \
  -o gradle/wrapper/gradle-wrapper.jar
```

## Первый запуск — чеклист

После клонирования репозитория:

```bash
# 1. Скачать gradle-wrapper.jar (если нет)
cd mobile
curl -L "https://raw.githubusercontent.com/gradle/gradle/v8.11.1/gradle/wrapper/gradle-wrapper.jar" \
  -o gradle/wrapper/gradle-wrapper.jar

# 2. Создать local.properties (подставить свой путь к AS)
cat > local.properties << 'EOF'
sdk.dir=/Users/YOUR_USER/Library/Android/sdk
org.gradle.java.home=/Users/YOUR_USER/Applications/Android Studio.app/Contents/jbr/Contents/Home
EOF

# 3. Проверить Gradle
./gradlew --version

# 4. Собрать Android
./gradlew :androidApp:assembleDebug

# 5. Установить Tuist и сгенерировать iOS-проект
cd iosApp
mise install
mise exec -- tuist generate
```

## Ключевые зависимости

### Shared (commonMain)

| Библиотека | Назначение | Desktop-аналог |
|---|---|---|
| **Ktor Client** | HTTP-запросы к Innertube | `fetch` / Fastify client |
| **KotlinX Serialization** | JSON парсинг | — (встроен в TS) |
| **KotlinX Coroutines** | Асинхронность | `Promise` / `async-await` |
| **SQLDelight** | Локальная SQLite БД | `conf` (persistent storage) |
| **Koin** | Dependency Injection | — (нет в desktop) |

### Android (androidMain)

| Библиотека | Назначение |
|---|---|
| **Jetpack Compose** | Декларативный UI (аналог Vue templates) |
| **Media3 ExoPlayer** | Аудиоплеер + MediaSession |
| **Navigation Compose** | Навигация между экранами |
| **Lifecycle Compose** | Реактивный state management |
| **WebKit** | WebView для Google Login |

### iOS (iosMain / Swift)

| Библиотека | Назначение |
|---|---|
| **Ktor Darwin** | HTTP-клиент (NSURLSession) |
| **SQLDelight Native** | SQLite через NativeSqliteDriver |
| **libsqlite3** | Системная SQLite (линкуется через Xcode) |
| **AVFoundation** | Аудиоплеер (системный фреймворк) |
| **WebKit** | WKWebView для Google Login |
| **MediaPlayer** | Lock screen / Control Center |

### Android Studio

|---|---|
