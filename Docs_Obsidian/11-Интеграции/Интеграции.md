## Система интеграций

Все интеграции реализуют единый интерфейс:

```typescript
// src/main/integrations/integration.ts
export default interface IIntegration {
  provide(...args: unknown[]): void;  // Инъекция зависимостей
  enable(): void;                     // Запуск
  disable(): void;                    // Остановка
  getYTMScripts(): { name: string; script: string }[];  // Скрипты для YTM View
}
```

### Жизненный цикл интеграции

```
1. new Integration()      ← Создание объекта (при запуске приложения)
2. integration.provide()  ← Передача store, memoryStore, ytmView
3. integration.enable()   ← Запуск (если включена в настройках)
4. integration.disable()  ← Остановка (при отключении в настройках)
```

> [!note] Аналогия
> `IIntegration` = Android `Service` с `onCreate()` / `onStartCommand()` / `onDestroy()`

## Companion Server

Самая сложная интеграция. HTTP API + WebSocket для удалённого управления.

### Архитектура

```
┌─────────────────────────────┐
│     Companion Server        │
│     (Fastify + Socket.IO)   │
│     http://0.0.0.0:9863     │
│                              │
│  ┌─────────────────────┐    │
│  │  REST API /api/v1/  │    │
│  │  ├── /auth/         │    │
│  │  ├── /state         │    │
│  │  ├── /command        │    │
│  │  └── /playlists      │    │
│  └─────────────────────┘    │
│                              │
│  ┌─────────────────────┐    │
│  │  WebSocket          │    │
│  │  /api/v1/realtime   │    │
│  └─────────────────────┘    │
└─────────────────────────────┘
```

### API Endpoints

| Метод | Путь | Назначение |
|---|---|---|
| `POST` | `/api/v1/auth/requestcode` | Запросить временный код авторизации |
| `POST` | `/api/v1/auth/request` | Обменять код на токен |
| `GET` | `/api/v1/state` | Текущее состояние плеера |
| `POST` | `/api/v1/command` | Выполнить команду (play, pause, next...) |
| `GET` | `/api/v1/playlists` | Список плейлистов пользователя |

### Аутентификация

```
Клиент ──POST /auth/requestcode──→ Server
         ←── { code: "ABCDE" } ──←

Клиент ──POST /auth/request { code: "ABCDE" }──→ Server
         (Показывает окно авторизации пользователю)
         ←── { token: "abc123..." } ──←

Клиент ──GET /state (header: Authorization: token)──→ Server
```

- Временный код истекает через 60 секунд
- Токены хранятся зашифрованными через `safeStorage`
- Максимум 5 одновременных окон авторизации
- Rate limiting через `@fastify/rate-limit`

### WebSocket (Real-time)

```typescript
// Клиент подключается к ws://host:9863/api/v1/realtime
// Получает events:
// - state-update (изменение состояния плеера)
// - playlist-created
// - playlist-deleted
```

> [!tip] Для мобильного приложения
> Companion Server API — готовый интерфейс для управления YTM с мобильного устройства.
> Мобильное приложение может быть **клиентом** этого API (как пульт управления).

## Discord Rich Presence

Показывает текущий трек в профиле Discord.

```
src/main/integrations/discord-presence/
├── index.ts                    # Основная логика
└── minimal-discord-client/     # Собственный Discord IPC клиент
    ├── index.ts                # Клиент
    ├── ipc.ts                  # IPC transport
    └── types.ts                # Типы
```

### Как работает

1. Подключается к Discord через IPC pipe (`discord-ipc-0`)
2. При смене трека — отправляет `SET_ACTIVITY`:
   - Название трека
   - Исполнитель
   - Обложка альбома
   - Прогресс

> [!note] Не использует discord.js
> Реализован минимальный Discord IPC клиент без зависимостей.

## Last.fm Scrobbling

Автоматический скробблинг треков в Last.fm.

```
src/main/integrations/last-fm/
├── index.ts       # Скробблинг + API
└── schemas.ts     # TypeBox-схемы
```

### Как работает

1. OAuth авторизация через Last.fm API
2. При прослушивании трека на X% (настраиваемо, по умолчанию 50%) — скробблинг
3. Метод `track.scrobble` + `track.updateNowPlaying`

### Настройки

| Ключ | Значение | Назначение |
|---|---|---|
| `lastfm.api_key` | `"2a69bcf..."` | API ключ Last.fm |
| `lastfm.secret` | `"46eea2..."` | API секрет |
| `lastfm.token` | Токен | OAuth токен |
| `lastfm.sessionKey` | Ключ сессии | Ключ авторизации |
| `lastfm.scrobblePercent` | `50` | % прослушивания для скробблинга |

## Volume Ratio

Логарифмическая регулировка громкости (для более естественного восприятия).

```
src/main/integrations/volume-ratio/
├── index.ts                          # Интеграция
└── script/
    ├── enable.script.js              # Скрипт включения
    ├── disable.script.js             # Скрипт выключения
    └── forceupdatevolume.script.js   # Принудительное обновление
```

Инжектирует скрипт в YTM View, который перехватывает установку громкости и применяет логарифмическую кривую.

## Динамическое управление интеграциями

При изменении настроек — интеграции включаются/выключаются на лету:

```typescript
store.onDidAnyChange((newState, oldState) => {
  // Companion Server
  if (newState.integrations.companionServerEnabled &&
      !oldState.integrations.companionServerEnabled) {
    companionServer.provide(store, memoryStore, ytmView);
    companionServer.enable();
  } else if (!newState.integrations.companionServerEnabled &&
             oldState.integrations.companionServerEnabled) {
    companionServer.disable();
  }
  
  // Аналогично для каждой интеграции...
});
```
